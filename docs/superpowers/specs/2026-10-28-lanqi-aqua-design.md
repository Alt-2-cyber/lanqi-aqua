# 澜启渔新 Web与鸿蒙应用设计

用户授权：创建Web端和原生鸿蒙App并上传公开GitHub仓库，用于开源比赛。首先交付演示模式与可对接真实设备的接口。无需等待设计审批。

## 交付与架构

- 新独立仓库lanqi-aqua，不修改原材料、旧应用或证书。
- React 19、Vite、TypeScript管理端，水质总览、多塘管理、设备控制、告警处理、投喂任务、日志、设置和CSV导出。
- Node 24、Express 5、SQLite持久API。Web和App共用API，所有变更服务端持久化。cookie与bearer两种会话；网关独立token。真实模式为空数据，用户按需注册配置。
- 原生ArkTS/ArkUI Stage模型鸿蒙API12应用，底部监测、设备、告警、我的导航，支持后端地址、演示登录、读数、塘口切换、指令和回执、告警确认/解决、投喂记录、登出。
- 仓库仅包含本次自有代码、原创SVG、公开示例配置及构建文档。旧签名和密钥不复制。Apache-2.0许可本次代码。

## 界面

桌面侧栏、浅灰绿色画布、白色开放面板、深青色主按钮、水体轮廓图和可交互趋势图；中文正文微软雅黑/苹方，数字使用等宽字体。主色#14695e、辅助青#33a59a、警报赭色#c47732，边框#e3e9e6。小屏改抽屉导航、单列内容。原生App同样的色彩层级，保留系统控件可访问性。缺失的图像生成工具不阻塞代码原生可视化；界面不依赖外部照片。

## 业务边界

所有演示数据清楚标识，设备命令pending后等待回执，离线拒绝。告警open到acknowledged到resolved。投喂完成为人工记录，不能冒充实物计量。网关带来源和幂等编号，过期或无效数据不触发执行。完整字段与端点见docs/API.md。

## 验证

真实HTTP测试验证身份、越权、持久化、输入校验、设备命令幂等及回执、告警状态机、任务、真实网关和导出。Web编译、浏览器完整操作、手机布局与控制台检查。鸿蒙使用本机DevEco SDK编译HAP；若无签名/设备，交付未签名HAP和自动签名指引并说明限制。最终检查公开文件和Git提交，创建公开仓库并推送。
