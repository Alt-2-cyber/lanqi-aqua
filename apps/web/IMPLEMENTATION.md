# 澜启渔新 Web 工作台

## 运行与构建

- 工作区包：`@lanqi/web`；React 19、TypeScript、Vite、lucide-react。
- 开发：在仓库根目录执行 `npm run dev --workspace @lanqi/web`。
- 检查与生产构建：`npm run check --workspace @lanqi/web`。
- 兼容性与趋势聚合回归测试：`npm run test --workspace @lanqi/web`（Node 24）。
- 开发服务为 `127.0.0.1:5173`，`/api` 代理至 `127.0.0.1:4300`；生产部署需同源提供 `/api`。
- 图标、鱼形标志、水体图和趋势图均为代码生成的矢量图，无远程字体、图片或第三方运行时服务。

## 已实现

- 根据服务运行模式显示演示入口或账号密码登录；使用带凭据请求和服务器 HttpOnly cookie，不保存浏览器令牌。
- 七个页面：总览、塘口管理、设备控制、告警中心、投喂计划、操作日志、系统设置；支持 URL hash 导航、浏览器前进后退、登出。
- 全局塘口选择、塘口筛选/搜索/新增/详情，水质 CSV 下载。
- 可用键盘选择的塘区水体图，以及可切换溶解氧、水温、pH 和 6/12/24 小时时段的 SVG 趋势。
- 多塘趋势按分钟对齐，各塘仅贡献一次最新观测，最多沿用五分钟内的值；离线和指标缺失塘口不纳入均值，横轴按实际时间间距绘制。
- 设备登记与编号复制、操作确认、等待回执、成功/失败/超时回执。设备状态不会在回执之前被乐观修改；离线和传感设备不提供开关。
- 指令幂等键兼容普通局域网 HTTP：优先 UUID，回退到随机字节或时间与本地序号。该键只用于请求去重，不是登录凭据。
- 告警确认与解决流程，状态/等级过滤；投喂计划创建、人工完成记录和取消确认。
- 日志来源过滤/搜索/分批显示，养殖场设置保存与刷新间隔调整。
- 常规刷新遵循服务设置，默认 5 秒；有待回执指令时每 1.2 秒检查；切回浏览器时刷新。
- 初次加载、请求失败、超时、会话过期、空状态、离线读数与操作反馈。
- `Pond.availableMetrics` 可选列表逐项控制当前有效值；缺失/过期指标显示“—”，不纳入溶解氧均值。现场状态显示“观测在线”或“观测待齐”，4.5 mg/L 关注线仅显示于演示模式。
- 桌面侧栏与手机抽屉导航；原生 dialog 对话框、Escape 关闭、键盘焦点、手机抽屉焦点循环、减少动态效果偏好。

## 文件组织

- `src/state/AppContext.tsx`：会话、快照轮询、变更请求、导航和提示。
- `src/lib`：网络与下载、日期/指标有效性处理。
- `src/components`：导航框架、对话框与基础组件、水体图和趋势图。
- `src/pages`：七个业务页面与登录页。
- `src/styles.css`：产品主题、页面布局和响应式样式。
